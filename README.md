# LethalPhonesVariableCallTimeout

## Description

A Lethal Company Mod and an addition to the mod LethalPhones by Scoops. LethalPhones has a fixed duration for call timeouts. Therefore LethalPhonesVariableCallTimeout lets you either configure this fixed duration or alternatively let the call timeout be determined by the length of the ringtones(e.g. if you have custom ringtones).


## Features

- Change LethalPhones call timeout duration, either to a fixed duration or variable based on ringtone length


## Technical Details

- Developed for Lethal Company v81 and LethalPhones 1.3.23.
- Two configurable modes:
  - `Fixed`: use a fixed timeout, configured through `FixedSeconds`. Default: 45 seconds.
  - `RingtoneLength`: calculate the timeout from the called phone's ringtone length.
- `FixedSeconds` also serves as a fallback if a usable ringtone length cannot be determined.
- In `RingtoneLength` mode:
  - `MaximumRingtoneSeconds` caps the calculated timeout, including the grace period.
  - `RingtoneGraceSeconds` adds an optional buffer to account for network delay.
- Applies to player and Switchboard calls. Enemy-initiated call timers remain unchanged.
- Install on all clients and use matching settings and ringtone files.

## Installation

- Install through r2modman or Thunderstore Mod Manager, including the required dependencies.
- Launch the game once to generate `BepInEx/config/lethalphones.calltimeout.cfg`.
- The default configuration uses a fixed 45-second timeout.
- To use individual ringtone lengths, set `Mode = RingtoneLength` in the configuration.
